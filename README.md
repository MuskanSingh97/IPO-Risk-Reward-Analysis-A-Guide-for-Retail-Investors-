# IPO Listing Gain Analysis

## Overview

This project analyzes **561 IPOs from 2010–2026** to identify whether institutional subscription, especially **QIB**, 
can predict listing-day gains.

##  Objective

* Analyze the relationship between QIB subscription and listing gains.
* Compare QIB, HNI, and RII subscription patterns.
* Identify profitable and risky IPO categories.
* Develop a data-driven risk-reward framework.

##  Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

##  Key Insights

* **QIB–Listing Gain correlation:** 0.62
* **RII–Listing Gain correlation:** 0.24
* **QIB > 50x success rate:** 97.25%
* **Average Listing Gain:** ~18%

##  Analysis

The project includes correlation analysis, descriptive statistics, QIB category analysis, profit/loss distribution, risk-reward classification, and multiple visualizations.

##  Conclusion

QIB subscription is a strong indicator of IPO listing performance, but it **does not guarantee profit**. Investors should also consider valuation, company fundamentals, and market conditions.
